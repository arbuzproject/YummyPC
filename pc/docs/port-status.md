# Состояние порта

Клиент собирается и запускается на Windows 10/11 x64 (JDK 21 + mpv).

## Готово

- Главная (карусель + ряды), топ, расписание, поиск с фильтрами, страница тайтла.
- Плеер: встроенный mpv, автопауза панели управления по бездействию, выбор качества,
  переключение озвучки/балансера, автопереход, автопропуск опенинга/эндинга с задержкой.
- Профиль: вход, счётчики, стрик онлайна, мини-календарь активности, время просмотра,
  «Продолжить просмотр», списки, история.
- Внешние балансеры через сервер: AniLibria (HLS 480/720/1080p) на странице тайтла и в плеере.
- Кэш ответов API 10 минут; иконка приложения.

## Ограничения

- Балансеры с IP-привязкой ссылок (VK/CVH/Aksor/Zedfilm/Alloha) резолвятся только на клиенте.
- AniLibria доступна не для всех тайтлов (каталог ~1900 релизов).
- Видео не проксируется сервером (1 CPU/2 GB достаточно только для API и индекса).
