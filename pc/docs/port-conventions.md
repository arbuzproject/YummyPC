# Правила порта

- Модули: `:api` (сеть/модели), `:extractors` (балансеры), `:player-ipc` (mpv IPC), `:app` (UI).
- UI — Compose Desktop, тёмная тема `YummyPalette`, русские подписи.
- Сетевые вызовы — только из корутин на `Dispatchers.IO` (Ktor-клиент сам это делает).
- Экстракторы возвращают `Result<ResolvedStream>` и не бросают исключений наружу.
- Секретов в клиенте нет: токены yani живут только на сервере.
- Проект — производная работа YummyTV (CC BY-NC 4.0), сохраняем `LICENSE`/`NOTICE`.
